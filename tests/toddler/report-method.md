## 測試怎麼做的

- **程式**：`tests/toddler/`（Playwright 1.58）。`npm run test:toddler` 會先打包（`npm run build`），用 `vite preview --port 4527` 開打包版，跑完產生這份報告。參數見 `tests/toddler/run.mjs` 開頭。
- **裝置**：觸控平板（`hasTouch`），1200×800 跑完整版；1280×800 跑精簡版（不發呆、亂玩步數減半）。所有觸控用 CDP 的 touch 事件送，和平板一樣產生 touch → pointer → click。
- **固定 seed**：孩子的每個動作、以及 App 裡的 `Math.random`（出題）都用同一個 seed，報告裡每個問題都有重現指令。語音長度、動畫時間還是會讓每次稍微不同，所以斷言都寫成「等到某個狀態」，不靠固定秒數。
- **頁內探針**（`tests/toddler/probe.js`，在 App 之前注入，只觀察）：每一幀量整頁圖層的透明度、縮放和九個點的覆蓋率；掛在 AudioContext 上記錄每一句語音（開始、長度、當時的字幕），抓兩句疊在一起；記錄頁面錯誤、DOM 變動、音效。
- **每個遊戲做的事**：連點站牌、遊戲卡進場 → 教學卡／示範／說明語音進行中搶著點、拖、畫 → 30 個隨機動作（亂點含邊緣、連點 5～10 下、拖到一半放手或拖出畫面、touchcancel、2～3 指手掌、亂畫、從畫布外畫進來、發呆）→ 一直選沒發光的選項 35 秒 → 完全不動 75 秒 → 切到背景（visibilitychange＋凍結頁面）4 秒再回來 → 一根手指拖曳時另一根按住回首頁 → 一進遊戲就按回首頁 → 點遊戲卡後轉場中馬上按住左上角 → `history.back()` → 亂玩幾下後重新整理。
- **每段之後檢查**：畫面有沒有卡住（45 秒內一直點都沒有任何變化）、白畫面、兩個畫面疊超過 5 秒、整頁縮放（0.97～1.0）、空白幀（覆蓋率 < 0.85）、透明度來回、語音疊播、缺音檔、主控台錯誤、示範中被記成作答、示範中留下墨跡、連點重複記錄、亂畫時畫到的地方有沒有墨跡。
- **畫面**：首頁、地圖、六個站點、貼紙本、家長閘門與家長區（含 `history.back()`）、今日冒險（亂玩 4 分鐘）、護眼休息、睡覺畫面、返回鍵、系統「減少動態效果」。

### 為了測試改的 src（不影響行為）

- `src/games/Shell.tsx`：新增 `demo` 屬性，只輸出成 `.stage[data-demo="1"]`。
- `src/games/draw/TraceGame.tsx`、`GlyphGame.tsx`、`ColoringGame.tsx`、`DotsGame.tsx`、`src/games/sheet/SheetGame.tsx`：把各自的示範狀態（`demo`、`handOn`、`demoInk`）傳給 Shell 的 `demo`。
- 其他遊戲（選擇、數數、排順序…）用畫面上已有的 `.teach-layer`（教學卡）和 `.demo-hand`（示範的手）判斷。幼兒設計準則建議的 `data-phase`、`data-accepting` 還沒加，等各遊戲的階段整理好再補；探針已經會讀 `data-phase`。

### 還沒辦法自動化的

- **紙感螢幕的實際殘影**：探針量的是每一幀的樣式數值（透明度、縮放、覆蓋率），看不到 NXTPAPER 螢幕更新慢造成的殘影；閃動類的問題要在平板上看一次。
- **聲音真的有沒有出來、音量、聽不聽得懂**：測試瀏覽器沒有喇叭，只能確認播放有開始、沒有兩句疊在一起。
- **孩子看不看得懂**（困惑類）：只能用「發呆時有沒有提示」「點了有沒有反應」間接判斷；要不要改設計還是要看孩子實際玩。
- **真正的 Android 返回手勢、切 App、螢幕固定（PIN）、全螢幕**：用 `history.back()`、`visibilitychange`＋頁面凍結模擬，不是系統層的事件。
- **觸控筆**：只模擬手指（touch）；Ink.tsx 的「筆在附近時忽略手指」沒有測。
- **選擇題以外的「答錯」**：排順序、開車、給蛋、找規律沒有固定的「錯誤選項」，用亂玩代替；選擇題用「沒有發光提示的選項」當成錯的。
- **完整玩完一局**：三歲亂玩不一定會玩完，所以「慶祝中按首頁」只有剛好玩完的遊戲才測到（表格裡是 —）。
- **幼兒設計準則裡要截圖比對、記錄台詞 key 或離線掃內容的規則**：PHASE-1（亮度比較）、PHASE-3／LANG-4（每句的 key）、PHASE-5（示範手速度）、PHASE-6、FB-3、LANG-1、LOAD-1～5、DRAW-4（離線出題統計）、DISPLAY-1／2（像素差）、LANG-3／5（靜音、去文字的自動玩家）、NAV-6、TIME-2／3、PARENT-1／3／4、DRAW-2／3／5／6／7、FB-1／2／4、TOUCH-2／4／5。這些需要 App 先加 `data-phase`／`data-accepting`，或另外寫離線腳本。
